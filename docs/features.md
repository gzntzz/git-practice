# 기능 목록 (Scope)

본 레포는 **가상의 티셔츠 스토어(iTshirt)**를 소재로, 팀 협업에서 필요한 문서/컨벤션을 연습하는 샌드박스

## Core Flows
- 상품 목록 조회
- 상품 디테일 조회
- 반응(좋아요/싫어요)
- 댓글
- 장바구니
- 구매

## Docs Map
- 샘플 데이터: `docs/data/tshirt-list.md`
- 디테일 페이지: `docs/spec/detail-page.md`
- 반응(좋아요/싫어요): `docs/spec/reactions.md`
- 댓글: `docs/spec/comments.md`
- 장바구니: `docs/spec/cart.md`

## Out of Scope
- 실결제/PG 연동
- 회원/권한(필요하면 별도 문서로 추가)
